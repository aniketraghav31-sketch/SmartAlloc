## About the Project

SmartAlloc is a Python-based project that helps manage room bookings for campus events.

In a university, different clubs, students, and departments need rooms for seminars, workshops, meetings, and other activities. Managing these bookings manually can sometimes lead to two events being scheduled in the same room at the same time.

We created SmartAlloc to make this process easier. It allows users to check rooms, book a room, view existing bookings, cancel bookings, and generate a report.

The program also checks for booking conflicts and suggests other available rooms or time slots when the requested room is already occupied.

## Features

- **View Rooms:** Display available rooms and their seating capacities.
- **Add Rooms:** Add new rooms to the room list.
- **Book a Room:** Create a booking by entering the room, date, time, event name, organizer, and number of attendees.
- **Conflict Detection:** Check whether another booking already exists for the same room and time.
- **Alternative Suggestions:** Suggest another suitable room or a different available time
